Supported Devices

All 53 Garmin devices supported by BodyMetrics v1.1.0, with display type and screen size.

June 14, 2026
devices compatibility

BodyMetrics v1.1.0 runs on 53 Garmin Connect IQ devices. The widget needs Connect IQ API level 2.3.0 or higher, and every device below is built and validated against that requirement.

How to Check Your Device

Find your watch model in the tables below. The Garmin ID is the identifier used by the build tools (for example fr265). All listed devices have a round screen and 768 KB of widget memory.

Testing

Behaviour is the same on every supported device. To launch the simulator for a specific device, run bash .vscode/run-sim.sh <device-id> from the repository root.

Not Supported in This Release

  • Forerunner 745, 945 and 945 LTE, Descent MK1, MK2 and MK2S, and MARQ Gen 1 models: they are excluded because of the Monkey C API 3.x limit of 9 arguments per method.
  • D2 Air: excluded because its widget memory (512 KB) is below the 768 KB used by the other devices.
